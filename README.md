# OWASP ZAP Compose

Containerized OWASP ZAP security testing environment with OWASP Juice Shop target application.

## Stack

* OWASP ZAP
* OWASP Juice Shop
* Docker Compose
* GitHub Version Control

## Purpose

Provide a reproducible and scalable environment for dynamic application security testing (DAST) against a vulnerable web application.

## Usage

```bash
docker compose up -d
```
